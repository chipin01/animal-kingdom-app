## 🧭 Expedition Features & Discovery Zones

### 🐾 8 Wild Discovery Zones (840+ Verified Entries)
1. **🐸 Amphibians**: Frogs, toads, salamanders, newts, and caecilians.
2. **🦋 Insects & Arachnids**: Butterflies, beetles, mantises, ants, and spiders with survival adaptations.
3. **🐋 Marine Life**: Whales, sharks, cephalopods, sea turtles, and deep-ocean coral ecosystems.
4. **🦁 Land Animals**: Apex predators, gentle giants, primates, and savanna herds.
5. **🐦 Birds of the World**: Raptors, songbirds, hummingbirds, parrots, and polar penguins.
6. **🌸 Flowers & Flora**: Rare carnivorous plants, giant redwoods, and tropical blooms.
7. **💎 Earth Gemstones & Minerals**: Crystals, opals, jade, quartz, and geological treasures.
8. **🦎 Reptiles**: Crocodilians, chameleons, monitors, snakes, and desert lizards.

### 🖼️ 4K Photorealistic Biome Wallpapers & Settings
- **Serengeti Twilight Savanna**: Golden-hour acacia horizon under fiery amber dusk.
- **Deep Amazonian Mist**: Towering rainforest giants and jungle waterfalls through morning fog.
- **Alpine Glacial Sanctuary**: Crystal turquoise mountain lake reflecting rugged snow peaks.
- **Great Barrier Reef Azure**: Sunlit azure ocean depths with corals, turtles, and rays.
- **Arctic Polar Aurora**: Emerald northern lights dancing over frozen fjords.
- **Custom Image URL Support**: Paste your own nature photograph wallpaper.
- **Adaptive Theme Biomes**: Seamless day/night ambient transitions.

### 🎨 Traditional Fine-Art Wildlife Gallery
- Features live animal masterpieces rendered in authentic traditional mediums:
  - 🖌️ **Watercolor**
  - ✏️ **Colored Pencil**
  - 🖍️ **Soft Pastel**
  - 🎨 **Acrylic Paint**
- High-resolution artwork inspection and multi-voice fine-art narration audio.

### 🌦️ Animal Weather Simulator
- Interactive biomes with real-time precipitation, wind, cloud, and ambient temperature physics.
- Live Irvine & global weather radar modes.

### 🔬 Inside Animal X-Ray & Anatomy Scanner
- Multi-layer canvas scanning: Skeleton, Musculature, Organs, and Nervous System.

### 🗺️ Live Wildlife Migration GPS Map Tracker
- Leaflet-powered geographic migration telemetry routes for Arctic Terns, Monarchs, Humpback Whales, and Monarch Butterflies.

### ⚔️ Creature Face-Off Battle Arena
- Stat-based combat simulator comparing bite force, top speed, armor, venom, and biome advantages.

### 🎵 Authentic Wildlife Audio Soundscapes
- Real bird calls, mammal roars, and synthesizer UI soundscapes.

## 💻 Running Locally

This application is built with standard web technologies and requires zero build steps or heavy dependencies:

### Quick Run with Node:
```bash
# Start local static server
node server.js

# Open in browser:
# http://localhost:3000
```

### Or run with any static web server:
```bash
npx serve .
# or
python -m http.server 3000
```

## 🚀 Publishing to GitHub Pages

1. Create a repository on GitHub (e.g. `animal-kingdom-app`).
2. Add remote and push:
   ```bash
   git remote add origin https://github.com/chipin01/animal-kingdom-app.git
   git branch -M main
   git push -u origin main
   ```
3. Enable GitHub Pages:
   - Go to your repository **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **GitHub Actions** (or **Deploy from a branch** → `main` / `root`).
   - Your site will be published at: `https://chipin01.github.io/animal-kingdom-app/`
